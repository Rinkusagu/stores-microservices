# Plans

All plans and progress for this project live **in this directory only** (`d:\code\projects\test`). Do not track plans or progress elsewhere.

## How to use

1. Add or update a plan file under `plans/`.
2. Link it from the index below.
3. Keep status and checkboxes in that plan file (and optionally mirror a short status here).
4. Update progress in-place as work completes — same directory, same files.

## Conventions

- **Plan files:** `plans/<kebab-name>.md`
- **Status values:** `planned` · `in-progress` · `blocked` · `done`
- **Progress:** checkboxes and a short Progress log inside each plan file
- **Scope:** never write plan/progress artifacts outside this project root
